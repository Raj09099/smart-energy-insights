# Smart Energy Insights

Design and develop a modern, responsive frontend for an AI Electricity Detection and Analysis System using HTML, CSS, JavaScript, and Bootstrap 5.

Theme:

- Modern AI + Smart Energy

- Dark mode with blue and green accents

- Clean glassmorphism UI

- Smooth animations

- Fully responsive for desktop, tablet, and mobile

Website Structure:

1. Login Page

- Attractive login card

- Project logo

- Email field

- Password field

- Remember Me checkbox

- Forgot Password link

- Login button

- Background animation with electricity circuit effects

2. Home Page

Hero Section:

- Title: AI Electricity Detection and Analysis System

- Subtitle explaining the system

- "Start Detection" button

- "Learn More" button

- Hero illustration related to AI and electricity

Navigation Bar:

- Home

- Detection

- Analysis

- AI Chatbot

- About

- Team

- Contact

- Login

Features Section

Create feature cards with icons:

- AI Fault Detection

- Energy Consumption Analysis

- Live Dashboard

- Smart Reports

- AI Chatbot

- Secure User Login

Statistics Section

Display animated counters:

- Devices Monitored

- Faults Detected

- Energy Saved

- Active Users

3. Detection Page

Create a professional dashboard with:

- Voltage input

- Current input

- Power input

- Frequency input

- Temperature input

- Detect button

Show AI Prediction Result Card:

- Normal

- Warning

- Critical

Display prediction using color coding:

Green = Normal

Orange = Warning

Red = Critical

Include charts for:

- Voltage

- Current

- Power

4. Analysis Page

Professional analytics dashboard.

Include:

- Line Chart

- Bar Chart

- Pie Chart

- Monthly Usage

- Weekly Usage

- Daily Usage

Show summary cards:

Total Consumption

Average Voltage

Power Factor

Efficiency

Estimated Electricity Bill

5. AI Chatbot Page

Create a chatbot interface like ChatGPT.

Features:

- Chat window

- User messages on right

- AI messages on left

- Typing animation

- Suggested questions:

  - Why is my power consumption high?

  - Detect electrical fault

  - Give energy saving tips

  - Explain voltage fluctuation

6. About Page

Include:

- Project Overview

- Objectives

- AI Technologies Used

- Machine Learning Workflow

- Benefits of the System

7. Team Page

Display team members in modern profile cards.

Each card includes:

- Social media icons

8. Contact Page

Modern contact form with:

- Send button

Also include:

Footer

Include:

- Quick Links

- Services

- Copyright

- Privacy Policy

Design Requirements:

- Glassmorphism cards

- Rounded corners (15px)

- Soft shadows

- Gradient backgrounds

- Smooth hover animations

- Scroll animations

- Responsive navigation menu

- Sticky navbar

- Animated buttons

- Professional icons using Font Awesome

- Charts using Chart.js

- Loading spinner

- Clean typography using Poppins font
